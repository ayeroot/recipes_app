# Captures d'écran

Placez ici les captures utilisées par le README principal :

- `home.png`      — écran d'accueil (liste + recherche)
- `detail.png`    — écran de détail d'une recette
- `form.png`      — formulaire d'ajout / d'édition
- `settings.png`  — réglages (thème clair/sombre/système)
- `mobile.png`    — rendu mobile (liste + NavigationBar)
- `tablet.png`    — rendu tablette (grille 2 colonnes)
- `desktop.png`   — rendu large (grille 3 colonnes + NavigationRail)

Pour capturer : lancez `flutter run` (ou `flutter run -d chrome`), puis
utilisez la capture d'écran de votre système / émulateur.
